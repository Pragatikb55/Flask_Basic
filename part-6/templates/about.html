📖 About This App

My Personal To-Do List

Stay organized and boost your productivity

Purpose

This app helps you organize your tasks, track progress, and manage priorities effectively.

Technology

Built with Flask, Python, HTML/CSS, and Jinja2 templating engine.

Features

Add, view, and filter tasks. Track status, priority, and due dates.

How to Use

  1. Add Tasks: Use the "Add Task" page to create new tasks
  2. Track Progress: Update task status as you work on them
  3. Set Priorities: Mark tasks as High, Medium, or Low priority
  4. Filter: View tasks by priority using the filter links
  5. Stay Organized: Set due dates and monitor your progress

Tips for Effective Task Management

  • Break large tasks into smaller, manageable steps
  • Review and update your task list daily
  • Focus on completing high-priority tasks first
  • Celebrate when you complete tasks!
